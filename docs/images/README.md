# Screenshot Assets

Upload the curated Modallia screenshots to this folder using these exact filenames:

- `dashboard.webp` — dashboard overview and business metrics
- `product-management.webp` — product list / management workflow
- `ai-studio.webp` — AI Studio configuration screen
- `ai-generation.webp` — AI generation progress state
- `ai-result.webp` — original vs AI-generated result
- `storefront.webp` — public storefront / catalog
- `product-detail.webp` — product detail and conversion flow
- `carousel-pro.webp` — Carousel Pro social-content workflow
- `mobile-experience.webp` — representative mobile screens

## Presentation Rules

- Prefer WebP or PNG.
- Keep desktop screenshots consistent in width and crop style.
- Avoid exposing credentials, private customer data or secrets.
- Prefer current Modallia branding when possible.
- Mobile evidence should show real responsive behavior rather than a desktop screenshot artificially resized.
