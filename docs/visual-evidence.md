# Visual Evidence Map

This document maps the main visual artifacts selected for the Modallia case study.

## Desktop Screens

1. **Dashboard overview**  
   General management area with business metrics, recent activity and shortcut cards.

2. **Product management**  
   Product list with item status, publication flow and quick access actions.

3. **AI Studio configuration**  
   Screen for product selection, avatar selection, generation type and scenario choice.

4. **AI generation in progress**  
   Progress-based feedback while the platform prepares the AI output.

5. **Original vs AI result**  
   Side-by-side comparison used for validation before approval.

6. **Public storefront**  
   Customer-facing catalog with hero banner, category filters and product cards.

7. **Product detail modal**  
   Product detail view with gallery, descriptive information, payment methods and WhatsApp CTA.

8. **Carousel Pro editor**  
   Social content workflow for assembling reusable promotional assets.

## Mobile Screens

1. **Mobile home / dashboard**
2. **Mobile AI result comparison**
3. **Mobile storefront catalog**
4. **Mobile product detail**
